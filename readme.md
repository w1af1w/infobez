# Система регистрации и авторизации пользователей

Проект демонстрирует реализацию базовой системы регистрации и авторизации пользователей с использованием Node.js, Express, SQLite и Argon2.

В проекте реализованы проверка логина и пароля, защита от распространённых и клавиатурных паролей, хеширование паролей и ограничение количества неудачных попыток входа.

## 1. Используемые технологии

1. HTML — структура страниц.
2. CSS — оформление интерфейса.
3. JavaScript — работа с формами и запросами.
4. Node.js — серверная часть.
5. Express — создание HTTP-сервера и маршрутов.
6. SQLite — хранение пользователей.
7. Argon2 — хеширование и проверка паролей.
8. common-password — проверка распространённых паролей.
9. Jest — автоматическое тестирование.

## 2. Запуск проекта

1. Установить Node.js.

2. Открыть папку проекта в терминале.

3. Установить зависимости:

```bash
npm install
```

4. Запустить сервер:

```bash
node src/server.js
```

5. Открыть в браузере:

```text
http://localhost:3000
```

### Запуск тестов

Для запуска автоматических тестов:

```bash
npm test
```

### Запуск бенчмарка

Для запуска бенчмарка:

```bash
node benchmarks/benchmark.js
```

Бенчмарк измеряет время хеширования и проверки паролей с помощью Argon2, а также время проверки паролей для нескольких пользователей.

## 4. Описание файлов

### public/index.html

Страница авторизации пользователя.

1. Содержит форму входа.
2. Пользователь вводит логин и пароль.
3. Подключает style.css и login.js.

### public/registration.html

Страница регистрации пользователя.

1. Содержит форму регистрации.
2. Пользователь вводит логин, пароль и повтор пароля.
3. Подключает style.css и script.js.

### public/style.css

Отвечает за внешний вид страниц.

1. Центрирует форму.
2. Оформляет поля ввода.
3. Оформляет кнопку.
4. Настраивает ссылки.
5. Добавляет эффекты наведения и фокуса.

### public/script.js

Отвечает за регистрацию пользователя.

Основные действия:

1. Перехватывает отправку формы.
2. Получает логин и пароль.
3. Проверяет совпадение паролей.
4. Отправляет данные на POST /register.
5. Получает ответ сервера.
6. Показывает сообщение пользователю.
7. Обрабатывает ошибку подключения.

### public/login.js

Отвечает за авторизацию пользователя.

Основные действия:

1. Перехватывает отправку формы.
2. Получает логин и пароль.
3. Отправляет данные на POST /login.
4. Получает ответ сервера.
5. Показывает сообщение пользователю.
6. Обрабатывает ошибку подключения.

В текущей версии проекта сессионный ключ не используется.

### src/server.js

Основной файл серверной части приложения.

Подключает:

1. Express — сервер и маршруты.
2. SQLite — базу данных.
3. Argon2 — хеширование и проверку паролей.
4. common-password — проверку распространённых паролей.

### validateLogin()

Проверяет логин:

1. Минимум 3 символа.
2. Максимум 30 символов.
3. Разрешены буквы, цифры, _ и -.

Функция возвращает массив найденных ошибок.

### validatePassword()

Проверяет пароль:

1. Длина от 8 до 128 символов.
2. Наличие заглавной буквы.
3. Наличие строчной буквы.
4. Наличие цифры.
5. Наличие специального символа.
6. Отсутствие распространённого пароля.
7. Отсутствие клавиатурных последовательностей.

Функция возвращает массив найденных ошибок.

### POST /register

Маршрут регистрации пользователя.

1. Получает логин и пароль.
2. Проверяет заполнение полей.
3. Проверяет логин.
4. Проверяет пароль.
5. Проверяет наличие пользователя в базе.
6. Хеширует пароль с помощью Argon2.
7. Сохраняет пользователя в SQLite.
8. Возвращает результат регистрации.

Исходный пароль в базе данных не хранится.

### POST /login

Маршрут авторизации пользователя.

1. Получает логин и пароль.
2. Проверяет количество неудачных попыток.
3. Находит пользователя в базе.
4. Проверяет пароль с помощью Argon2.
5. При неправильном пароле увеличивает счётчик попыток.
6. После трёх неправильных попыток вход блокируется на 60 секунд.
7. При успешном входе счётчик попыток сбрасывается.

## 5. Ограничение попыток входа

Используются следующие настройки:

```text
MAX_ATTEMPTS = 3
BLOCK_TIME = 60 секунд
```

После трёх неправильных попыток вход для данного логина временно блокируется.

После окончания блокировки пользователь снова может выполнить вход.

## 6. Автоматические тесты

### tests/validation.test.js

Содержит автоматические тесты Jest для функций:

1. validateLogin().
2. validatePassword().

Проверяются:

1. Корректный логин.
2. Слишком короткий логин.
3. Слишком длинный логин.
4. Недопустимые символы.
5. Корректный пароль.
6. Минимальная и максимальная длина пароля.
7. Отсутствие заглавной буквы.
8. Отсутствие строчной буквы.
9. Отсутствие цифры.
10. Отсутствие специального символа.
11. Клавиатурные последовательности.
12. Распространённые пароли.

Всего реализовано 14 тестов.

Запуск тестов:

```bash
npm test
```

## 7. Бенчмарк

### benchmarks/benchmark.js

Используется для измерения производительности Argon2.

Проверяется:

1. Время хеширования одного пароля.
2. Время проверки одного пароля.
3. Время проверки паролей для 1 пользователя.
4. Время проверки паролей для 5 пользователей.
5. Время проверки паролей для 10 пользователей.
6. Время проверки паролей для 20 пользователей.

Запуск:

```bash
node benchmarks/benchmark.js
```

При текущем запуске были получены следующие результаты:

| Операция             |     Время |
| -------------------- | --------: |
| Hash одного пароля   |  24.49 мс |
| Verify одного пароля |  21.82 мс |
| 1 пользователь       |  24.65 мс |
| 5 пользователей      |  48.94 мс |
| 10 пользователей     |  74.88 мс |
| 20 пользователей     | 128.89 мс |

Результаты бенчмарка зависят от характеристик компьютера и текущей нагрузки системы.

## 9. Безопасность

В проекте реализованы следующие механизмы защиты:

1. Проверка сложности пароля.
2. Проверка распространённых паролей.
3. Проверка клавиатурных последовательностей.
4. Хеширование паролей с помощью Argon2.
5. Отсутствие хранения исходных паролей.
6. Ограничение количества попыток входа.
7. Временная блокировка после трёх неудачных попыток.
